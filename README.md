# Scripts: Reconstitution of Human Brain Cell Diversity in Organoids via Four Protocols

This repository includes R scripts generated to process NGS data analyzed in “*Quantitative profiling of human brain organoid cell diversity across four protocols and multiple cell lines*” (Naas et al. 2025, *Cell Reports*, [DOI: 10.1016/j.celrep.2025.116168](https://doi.org/10.1016/j.celrep.2025.116168) and *bioRxiv*, [DOI: 10.1101/2024.11.15.623576](https://doi.org/10.1101/2024.11.15.623576)).

The therein introduced NEST-Score is available as R package on <https://github.com/jn-goe/NESTScore>.

Corresponding source data to reproduce all figures and tables presented in the manuscript are available via Zenodo archive [DOI: 10.5281/zenodo.13742634](https://doi.org/10.5281/zenodo.13742634).
